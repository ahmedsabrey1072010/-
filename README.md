# بوابة مصر الرقمية والتعليمية | Egypt Digital & Education Portal

> مشروع تعليمي يهدف لتجميع إنجازات التحول الرقمي في مصر - المنصات التعليمية والمشروعات القومية في مكان واحد.

## 📌 نبذة عن المشروع
الموقع يعرض 7 محاور رئيسية للتحول الرقمي:
1. بنك المعرفة المصري (EKB)
2. منظومة الامتحانات والإدارة الإلكترونية
3. منصات التعلم والتواصل (مدرستنا)
4. مدارس التكنولوجيا التطبيقية والذكاء الاصطناعي
5. بوابة مصر الرقمية
6. العاصمة الإدارية والمدن الذكية
7. مركز البيانات والحوسبة السحابية PCCC

بالإضافة لـ 6 كروت مشروعات قومية وقائمة اهتمامات تفاعلية.

## ✨ المميزات
- **بحث ذكي:** ابحث بالعربي أو الإنجليزي (EKB, تابلت, digital...) وينقلك للقسم مع تمييز بصري
- **وضع داكن / فاتح:** مع حفظ الاختيار في LocalStorage
- **تغيير لغة كامل:** عربي ↔ إنجليزي لكل النصوص حتى النقاط والـ placeholders
- **قائمة متابعة:** إضافة وحذف منصات مع حفظها حتى بعد إغلاق المتصفح
- **اقرأ المزيد:** Toggle لإظهار التفاصيل بدون إعادة تحميل
- **متجاوب 100%:** Grid و Media Query للموبايل

## 🛠️ التقنيات المستخدمة
- **HTML5:** Semantic tags, data-ar/data-en للترجمة
- **CSS3:** Variables, Flexbox, Grid, Transitions, Dark Theme
- **JavaScript Vanilla:** LocalStorage, DOM Manipulation

## 💡 طريقة الاستخدام
1. استخدم شريط التنقل للانتقال بين الأقسام
2. جرب البحث عن "بنك المعرفة" أو "digital"
3. دوس "اقرأ المزيد" لعرض المميزات
4. أضف منصاتك المفضلة في "قائمة اهتماماتي"
5. جرب زر 🌙 و زر English
